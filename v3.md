# UPI QR Version 3.0.0 Documentation

Welcome to the **v3.0.0** release of `@omkarbhosale/upiqr`. This release introduces transaction splitting (`splitTransactionQR`), end-to-end Zod 4 validation, comprehensive TypeScript declarations, and optimized single QR generation.

---

## What's New in v3.0.0

- ✂️ **Transaction Splitting (`splitTransactionQR`)**: Automatically breaks transactions above ₹2,000 into ₹1,999 intervals (e.g., ₹5,000 becomes ₹1,999 + ₹1,999 + ₹1,002).
- 🛡️ **Upgraded Zod Validation**: Built with Zod 4, providing strict validation for UPI IDs, transaction limits, and outputs.
- 🏷️ **Optional Transaction Metadata**: Support for payee name (`name`), transaction note (`note`), and currency (`currency`, defaults to `INR`).
- ⚡ **Precision Math**: Built using paise-level integer math to prevent floating-point rounding errors.
- 📦 **Dual Import Support**: Full support for both Named Imports and Default Imports.
- 📘 **TypeScript Type Declarations**: Shipped with complete `.d.ts` and `.d.ts.map` declaration files.

## 1. `splitTransactionQR(params)`

Splits large transactions exceeding a threshold (default ₹2,000) into ₹1,999 intervals and generates a QR code for each chunk concurrently.

### Why Split at ₹1,999?
Under NPCI guidelines, transactions $\le$ ₹2,000 often bypass merchant interchange fees on PPI wallets and qualify for streamlined processing. Splitting larger payments into ₹1,999 chunks ensures each transaction remains under the ₹2,000 threshold.

### Function Signature
```typescript
function splitTransactionQR(params: SplitQRParams): Promise<SplitQRItem[]>;
```

### Parameters (`SplitQRParams`)

| Parameter | Type | Required | Default | Description |
| :--- | :--- | :---: | :---: | :--- |
| `UPI_ID` | `string` | **Yes** | — | Valid UPI ID (e.g., `merchant@okhdfcbank`, `user@upi`). |
| `AMOUNT` | `number` | **Yes** | — | Total transaction amount (positive number up to ₹10,00,000). |
| `splitInterval` | `number` | No | `1999` | Maximum amount per split chunk. |
| `threshold` | `number` | No | `2000` | Amount above which splitting is triggered. If `AMOUNT <= threshold`, only 1 QR is generated. |
| `name` | `string` | No | — | Payee name (`pn`). |
| `note` | `string` | No | — | Transaction note (`tn`). Each chunk automatically appends `(Part X/Y)`. |
| `currency` | `string` | No | `"INR"` | Currency code. |

### Return Value (`SplitQRItem[]`)

An array of objects, where each object contains:

| Property | Type | Description |
| :--- | :--- | :--- |
| `id` | `string` | Unique UUID (`v4`) for this specific split QR. |
| `amount` | `number` | The split portion amount. |
| `image` | `string` | Base64-encoded Data URL of the generated QR code (`data:image/png;base64,...`). |

---

### Code Examples

#### Basic Split (₹5,000)
```typescript
import { splitTransactionQR } from "@omkarbhosale/upiqr";

const generateSplits = async () => {
  try {
    const qrs = await splitTransactionQR({
      UPI_ID: "store@upi",
      AMOUNT: 5000,
    });

    console.log(qrs);
  } catch (error) {
    console.error("Split generation error:", error.message);
  }
};

generateSplits();
```

#### Custom Split Interval & Threshold
You can customize the threshold and split chunk size:

```typescript
import { splitTransactionQR } from "@omkarbhosale/upiqr";

const qrs = await splitTransactionQR({
  UPI_ID: "store@upi",
  AMOUNT: 1000,
  threshold: 500,     // Split anything above ₹500
  splitInterval: 400, // Chunk in ₹400 intervals
  name: "Omkar Store",
  note: "Order #12345"
});

// Returns 3 QRs: ₹400 + ₹400 + ₹200
```

---

#### Amounts Within Threshold ($\le$ ₹2,000)
If the transaction is less than or equal to the threshold, it will **not** split and will return a single item:

```typescript
const qrs = await splitTransactionQR({
  UPI_ID: "store@upi",
  AMOUNT: 1500,
});

// Returns 1 QR: [ { id: "...", amount: 1500, image: "..." } ]
```

## 2. `generateQR(params)`

Generates a single UPI QR code as a base64 Data URL.

### Function Signature
```typescript
function generateQR(params: QRParams): Promise<string>;
```

### Parameters (`QRParams`)

| Parameter | Type | Required | Default | Description |
| :--- | :--- | :---: | :---: | :--- |
| `UPI_ID` | `string` | **Yes** | — | Valid UPI ID handle. |
| `AMOUNT` | `number` | **Yes** | — | Amount to receive (positive number $\le$ ₹1,00,000). |
| `name` | `string` | No | — | Payee Name (`pn`). |
| `note` | `string` | No | — | Transaction note (`tn`). |
| `currency` | `string` | No | `"INR"` | Currency code. |

### Example
```typescript
import { generateQR } from "@omkarbhosale/upiqr";

const createSingleQR = async () => {
  try {
    const qrDataUrl = await generateQR({
      UPI_ID: "omkar@upi",
      AMOUNT: 750,
      name: "Omkar Bhosale",
      note: "Coffee bill",
    });

    console.log(qrDataUrl); // data:image/png;base64,iVBORw0KGgo...
  } catch (error) {
    console.error("QR creation failed:", error.message);
  }
};

createSingleQR();
```

## 3. Zod Schemas & Validation

All parameters are validated at runtime before generating any QR code. If invalid input is provided, a descriptive validation error is thrown.

### Exported Schemas
You can import the schemas directly to pre-validate inputs in your own forms or API handlers:

```typescript
import {
  upiIdSchema,
  qrParamsSchema,
  splitQRParamsSchema,
  splitQRItemSchema
} from "@omkarbhosale/upiqr";

// Validate a UPI ID directly
const result = upiIdSchema.safeParse("invalid-upi");
if (!result.success) {
  console.log(result.error.issues[0].message);
  // "Invalid UPI ID format. Expected format: username@bank"
}
```

### Validation Rules
- **UPI ID**: Must match regex `/^[\w.-]+@[\w.-]+$/`, minimum 3 characters, maximum 50 characters, trimmed of whitespace.
- **Single QR Amount**: Must be positive, finite, and $\le$ ₹1,00,000.
- **Split QR Amount**: Must be positive, finite, and $\le$ ₹10,00,000.
- **Error Handling**: Throws an `Error` with format: `Validation error: field: message`.

## 4. Import Compatibility

`@omkarbhosale/upiqr` supports both named and default imports:

### Named Imports (Recommended)
```typescript
import { generateQR, splitTransactionQR } from "@omkarbhosale/upiqr";
```

### Default Import (Backwards Compatible)
```typescript
import upiqr from "@omkarbhosale/upiqr";

// Use directly as generateQR
const single = await upiqr({ UPI_ID: "user@upi", AMOUNT: 500 });

// Or call splitTransactionQR
const splits = await upiqr.splitTransactionQR({ UPI_ID: "user@upi", AMOUNT: 5000 });
```

### TypeScript Types
```typescript
import type { QRParams, SplitQRParams, SplitQRItem } from "@omkarbhosale/upiqr";
```
