# UPI QR Python Version 3.0.0 Documentation

Welcome to the **v3.0.0** release of `omkarbhosale-upi-qr`. This release introduces transaction splitting (`splitTransactionQR`), end-to-end Pydantic schema validation (with Zod-compatible `.safeParse` support), precision paise-level integer arithmetic, transaction metadata (`name`, `note`, `currency`), and flexible invocation modes.

---

## What's New in v3.0.0

- ✂️ **Transaction Splitting (`splitTransactionQR`)**: Automatically breaks transactions above ₹2,000 into ₹1,999 intervals (e.g., ₹5,000 becomes ₹1,999 + ₹1,999 + ₹1,002).
- 🛡️ **Pydantic Validation (Zod Parity)**: Strict schema validation powered by Pydantic v2 with `.safeParse()` and `.parse()` support for UPI IDs, amounts, and metadata.
- 🏷️ **Optional Transaction Metadata**: Support for payee name (`name`), transaction note (`note`), and currency (`currency`, defaults to `INR`).
- ⚡ **Precision Math**: Built using paise-level integer math (`round(amount * 100)`) to prevent floating-point rounding errors.
- 📦 **Dual Import & Flexible Calls**: Support for named imports, Pythonic snake_case aliases, callable default export (`upiqr`), and dict/keyword/positional arguments.
- 📘 **Type Annotations**: Shipped with full Python type hints and Pydantic models (`QRParams`, `SplitQRParams`, `SplitQRItem`).

## 1. `splitTransactionQR(*args, **kwargs)`

Splits large transactions exceeding a threshold (default ₹2,000) into ₹1,999 intervals and generates a QR code for each chunk concurrently.

### Why Split at ₹1,999?
Under NPCI guidelines, transactions $\le$ ₹2,000 often bypass merchant interchange fees on PPI wallets and qualify for streamlined processing. Splitting larger payments into ₹1,999 chunks ensures each transaction remains under the ₹2,000 threshold.

### Function Signature
```python
def splitTransactionQR(*args, **kwargs) -> List[SplitQRItem]:
```

*(Also available as `split_transaction_qr`)*

### Parameters (`SplitQRParams` / Keyword Arguments / Dict)

| Parameter | Type | Required | Default | Description |
| :--- | :--- | :---: | :---: | :--- |
| `UPI_ID` / `upi_id` | `str` | **Yes** | — | Valid UPI ID (e.g., `merchant@okhdfcbank`, `user@upi`). |
| `AMOUNT` / `amount` | `float | int` | **Yes** | — | Total transaction amount (positive number up to ₹10,00,000). |
| `splitInterval` / `split_interval` | `float | int` | No | `1999` | Maximum amount per split chunk. |
| `threshold` | `float | int` | No | `2000` | Amount above which splitting is triggered. If `AMOUNT <= threshold`, only 1 QR is generated. |
| `name` | `str` | No | `None` | Payee name (`pn`). |
| `note` | `str` | No | `None` | Transaction note (`tn`). Each chunk automatically appends `(Part X/Y)`. |
| `currency` | `str` | No | `"INR"` | Currency code. |

### Return Value (`List[SplitQRItem]`)

A list of `SplitQRItem` objects. Each item supports both attribute access (`item.amount`) and dictionary indexing (`item["amount"]`):

| Property | Type | Description |
| :--- | :--- | :--- |
| `id` | `str` | Unique UUID (`v4`) for this specific split QR. |
| `amount` | `int | float` | The split portion amount. |
| `image` | `str` | Base64-encoded Data URL of the generated QR code (`data:image/png;base64,...`). |

---

### Code Examples

#### Basic Split (₹5,000)
```python
from omkarbhosale_upi_qr import splitTransactionQR

splits = splitTransactionQR({
    "UPI_ID": "store@upi",
    "AMOUNT": 5000,
})

for item in splits:
    print(f"ID: {item.id} | Amount: Rs. {item.amount}")
    print(f"Image: {item.image[:40]}...\n")
```

#### Custom Split Interval & Threshold
You can customize the threshold and split chunk size:

```python
from omkarbhosale_upi_qr import splitTransactionQR

splits = splitTransactionQR(
    UPI_ID="store@upi",
    AMOUNT=1000,
    threshold=500,     # Split anything above ₹500
    splitInterval=400, # Chunk in ₹400 intervals
    name="Omkar Store",
    note="Order #12345"
)

# Returns 3 QRs: ₹400 + ₹400 + ₹200
# Notes: "Order #12345 (Part 1/3)", "Order #12345 (Part 2/3)", "Order #12345 (Part 3/3)"
```

---

#### Amounts Within Threshold ($\le$ ₹2,000)
If the transaction is less than or equal to the threshold, it will **not** split and will return a single item:

```python
splits = splitTransactionQR(
    UPI_ID="store@upi",
    AMOUNT=1500,
)

# Returns 1 QR: [SplitQRItem(id="...", amount=1500, image="data:image/png;base64,...")]
```

## 2. `generateQR(*args, **kwargs)`

Generates a single UPI QR code as a base64 Data URL.

### Function Signature
```python
def generateQR(*args, **kwargs) -> str:
```

*(Also available as `generate_qr`)*

### Parameters (`QRParams` / Keyword Arguments / Dict)

| Parameter | Type | Required | Default | Description |
| :--- | :--- | :---: | :---: | :--- |
| `UPI_ID` / `upi_id` | `str` | **Yes** | — | Valid UPI ID handle. |
| `AMOUNT` / `amount` | `float | int` | **Yes** | — | Amount to receive (positive number $\le$ ₹1,00,000). |
| `name` | `str` | No | `None` | Payee Name (`pn`). |
| `note` | `str` | No | `None` | Transaction note (`tn`). |
| `currency` | `str` | No | `"INR"` | Currency code. |

### Example

```python
from omkarbhosale_upi_qr import generateQR

# Keyword Arguments
qr_data_url = generateQR(
    UPI_ID="omkar@upi",
    AMOUNT=750,
    name="Omkar Bhosale",
    note="Coffee bill",
)
print(qr_data_url) # data:image/png;base64,iVBORw0KGgo...

# Dictionary payload
qr_data_url = generateQR({
    "UPI_ID": "omkar@upi",
    "AMOUNT": 750,
})

# Positional Arguments (Backwards-compatible)
qr_data_url = generateQR("omkar@upi", 750)
```

## 3. Schemas & Runtime Validation

All parameters are validated at runtime before generating any QR code. If invalid input is provided, a descriptive validation error is thrown.

### Exported Schemas (Zod-compatible)
You can import the schemas directly to pre-validate inputs in your own FastAPI / Flask handlers, forms, or scripts:

```python
from omkarbhosale_upi_qr import (
    upiIdSchema,
    qrParamsSchema,
    splitQRParamsSchema,
    splitQRItemSchema
)

# Validate a UPI ID directly
result = upiIdSchema.safeParse("invalid-upi")
if not result.success:
    print(result.error.issues[0].message)
    # "Invalid UPI ID format. Expected format: username@bank"
else:
    print("Valid UPI:", result.data)
```

### Pre-validating Full Parameters
```python
result = splitQRParamsSchema.safeParse({
    "UPI_ID": "store@upi",
    "AMOUNT": 5000,
    "splitInterval": 1999,
})

if result.success:
    validated_params = result.data  # SplitQRParams instance
else:
    print("Error:", result.error.message)
```

### Validation Rules
- **UPI ID**: Must match regex `^[\w.-]+@[\w.-]+$`, minimum 3 characters, maximum 50 characters, trimmed of whitespace.
- **Single QR Amount**: Must be positive, finite number $\le$ ₹1,00,000.
- **Split QR Amount**: Must be positive, finite number $\le$ ₹10,00,000.
- **Error Handling**: Throws a `UPIValidationError` (inherits from `ValueError`) with format: `Validation error: field: message`.

## 4. Import & Usage Compatibility

`omkarbhosale-upi-qr` supports named imports, pythonic aliases, and a callable default style matching JavaScript packages:

### Named Imports (Recommended)
```python
from omkarbhosale_upi_qr import generateQR, splitTransactionQR
```

### Pythonic snake_case Imports
```python
from omkarbhosale_upi_qr import generate_qr, split_transaction_qr
```

### Callable Object (`upiqr`)
Mimics default import behavior from the JavaScript package:
```python
from omkarbhosale_upi_qr import upiqr

# Use directly as generateQR
single = upiqr(UPI_ID="user@upi", AMOUNT=500)

# Or call splitTransactionQR as a method
splits = upiqr.splitTransactionQR(UPI_ID="user@upi", AMOUNT=5000)
```

## 5. Pydantic Models & Typing

For typed Python applications (e.g., FastAPI, Pydantic settings), you can import the underlying Pydantic models directly:

```python
from omkarbhosale_upi_qr import QRParams, SplitQRParams, SplitQRItem

# Direct model initialization with validation
params = SplitQRParams(
    UPI_ID="merchant@okhdfcbank",
    AMOUNT=7500.0,
    splitInterval=1999.0,
    threshold=2000.0,
    name="Merchant Store",
    note="Invoice #88"
)

# Convert SplitQRItem to dict
split_dict = splits[0].to_dict()
```
